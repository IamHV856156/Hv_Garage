# Hv_Garage // Harshit Vashisht

Welcome to my digital workshop. This is where I experiment with the intersection of code, motion, and design.

The web shouldn’t feel like a static document—it should feel like a tactile experience. **Hv_Garage** is my space to build interfaces that feel alive, where every interaction is intentional and every transition serves the narrative.

---

### 🎨 The Philosophy
I believe in **High-Fidelity digital experiences.**
* **Minimalism as Architecture:** Every pixel has a purpose.
* **Motion as Lifeblood:** If it doesn’t move, it feels dead. I use motion to guide, delight, and inform the user.
* **Tactile Web:** I treat the browser as a physical canvas where code meets physics.


---

### 🚀 The Tech Arsenal
I craft experiences using the modern web stack:

* **Framework:** [Next.js](https://nextjs.org/) (Performance & SEO optimization).
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (For scalable UI construction).
* **Motion:** [Framer Motion](https://www.framer.com/motion/) (The engine that brings the interface to life).
* **Icons:** [Lucide React](https://lucide.dev/).
* **State Management:** React Context API (Used to orchestrate complex global UI states).


---

### 🛠️ Key Features
* **Glassmorphic Design:** A clean, modern aesthetic utilizing backdrop blurs and subtle borders.
* **Interactive Hero:** A responsive, 3D-perspective hero section that reacts to your mouse movements.
* **Atmospheric Audio:** A custom-built music modal that allows users to set the mood while browsing.
* **Global State Sync:** Music controls and "Now Playing" indicators are synchronized across the entire site using React Context.
* **Custom Terminal:** A retro-inspired command interface for a unique take on the "About" section.
